# Clean Air Climate Resilience

Notebook-based AQI modeling project using the city-day air quality dataset. No project Python modules are required; run notebooks in order from the repository root.

## Structure

```text
data/raw/          Source dataset (city_day.csv is included)
data/interim/      Cleaned dataset generated by preprocessing.ipynb
data/processed/    Feature data and prediction inputs/outputs
models/            Trained model artifact
notebooks/         Exploratory analysis notebooks
src/               Pipeline notebooks for loading, preprocessing, features, training, evaluation, prediction
reports/           Holdout metrics and generated figures
tests/             Reserved for notebook-based verification
```

## Setup and run

Install the dependencies in `requirements.txt`, then use the notebook workflow below.

Notebook workflow:

1. `src/preprocessing.ipynb` cleans the CSV and writes `data/interim/city_day_clean.csv`.
2. `src/features.ipynb` creates daily date and lag features in `data/processed/city_day_features.csv`.
3. `src/train.ipynb` is a self-contained training workflow. It cleans the source, trains and saves `models/random_forest_aqi.pkl`, and writes holdout metrics to `reports/metrics.csv`.
4. `src/evaluate.ipynb` displays the saved holdout metrics.
5. `src/predict.ipynb` runs batch predictions when `data/processed/input.csv` is present with the predictor columns shown by the notebook.

`src/data_loader.ipynb` contains examples for loading available input CSVs. `notebooks/` contains exploratory analysis. The optional `app/app.ipynb` is a demo stub.
